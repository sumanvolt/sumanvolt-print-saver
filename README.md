## 🎯 Purpose

Competitive exam aspirants download hundreds of megabytes of daily class notes and slide PDFs (from PW, Unacademy, YouTube, coaching apps). Printing them is expensive because:
1. One slide per single sheet wastes 70–80% paper.
2. Dark-mode slides (black backgrounds with white text) drain printer ink cartridges in minutes.
3. Third-party cloud converter websites pose privacy risks and often require payments or limit file sizes.

**SumanVolt solves this completely for free, locally in your browser.**

---

## ✨ Features

* 🖨️ **Lossless Vector N-Up (2, 4, 6, 9, 16-Up):** Embeds native PDF fonts and vector lines directly using `pdf-lib` without any pixelation or blurriness.
* 🌗 **Dark Mode Slide Inversion (Ink Saver):** Automatically inverts black background lecture slides to crisp white pages with black text using a local in-memory 300 DPI engine.
* 🔒 **100% Client-Side & Private:** Nothing is uploaded to any server. Your study materials and sensitive notes remain strictly inside your browser.
* 📱 **PWA & Offline Enabled:** Install it like a native mobile or desktop app and use it at the print shop even without internet connectivity.
* 📏 **Custom Margins:** Adjust spacing from 0 to 20mm to maximize writable margins.
